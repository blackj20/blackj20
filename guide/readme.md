# Guide de Pilotage du Site EMC Sarlu

## ⚠️ AVERTISSEMENTS IMPORTANTS

### 🔴 INTERDICTION : Uploads de Vidéos
**NE JAMAIS essayer d'uploader une vidéo sur le site.** Le système n'est pas configuré pour gérer les fichiers vidéo et cela peut causer des dysfonctionnements graves.

### 🔴 MOT DE PASSE - Sécurité Critique
- **Le mot de passe NE DOIT JAMAIS être perdu** car il n'existe pas de système de récupération.
- Conservez votre mot de passe dans un endroit sûr et sécurisé.
- En cas de perte de mot de passe, le compte sera inaccessible.

### ⏰ EXPIRATION DU TOKEN
- Le token d'authentification **expire tous les 3 jours**.
- Vous devrez vous reconnecter régulièrement.
- Prévoyez des authentifications avant le délai d'expiration pour maintenir l'accès.

## 📋 Guide Général de Gestion

### Avant de commencer
1. Consultez la documentation du site pour bien comprendre son fonctionnement
2. Prenez connaissance de toutes les fonctionnalités disponibles
3. Testez les opérations en environnement de test avant la production

### Conseils de Sécurité
- Changez régulièrement vos pratiques de gestion des accès
- Documentez tous les accès et modifications importantes
- Assurez-vous que le mot de passe reste confidentiel
